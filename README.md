# Simple QR Code Generator Web App

This is a simple web application that allows users to generate QR codes from any text or URL input. The project is built using **HTML**, **CSS**, and a bit of **JavaScript**. It uses a free QR code generation API to display the QR code dynamically.

---

![QR Generator Preview2](images/ss2.png)

---

## 💻 Features
- Enter any text or URL to generate a QR code
- Dynamic QR code generation via API
- Minimal and responsive design
- Error indication when input is empty

---

## 🚀 Getting Started
To run this project locally, simply follow these steps:

### 1. Clone the repository
```bash
   git clone https://github.com/HpareBaby/js_projects.git -b simple-qr-generator simple-qr-generator
```

### 2. Navigate to the project directory
```bash
cd simple-qr-generator
```

### 3. Open `index.html` in your browser
You can just double-click the file or use a local development server like Live Server if you have VS Code.

## 📌 Notes
- The app uses `https://api.qrserver.com/v1/create-qr-code/` to generate QR codes on the fly.
- No installation or build steps required.

# Simple To-Do List Web App

A minimalist To-Do List application built with **HTML**, **CSS**, and **JavaScript**. It allows users to add, complete, and delete tasks, with data persistence via **Local Storage**.

---
## 📸 Preview
![To-Do App Preview](images/ss1.png)

---

## 💻 Features

- **Add Tasks**: Type a task and click **Add** or press **Enter**.
- **Mark Complete**: Click on a task to toggle its completion state.
- **Delete Tasks**: Click the ✕ icon next to a task to remove it.
- **Persistent Storage**: Tasks are saved to Local Storage, so they persist on page reload.
- **Responsive Design**: Works across desktop and mobile viewports.

## 🚀 Getting Started

Follow these steps to run the project locally:

### 1. Clone the repository
```bash
git clone https://github.com/HpareBaby/js_projects.git -b simple-todo-app simple-todo-app
```

### 2. Navigate to the project folder
```bash
cd simple-todo-app
```

### 3. Open in Browser
Open `index.html` directly in your browser or use a live-server extension:
```bash
# If you have VS Code Live Server installed:
code .
# then click "Go Live"
```
